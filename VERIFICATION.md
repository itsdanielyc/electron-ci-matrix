## Unverified

- The shared geometry baseline is rewritten by whichever capture job's artifact is copied last (windows); macOS differs by 4 px on the form and the elements below it, inside the 8 px tolerance.
- Tier 3 has not been seen red on purpose; only its "missing baseline" failure was observed.
- Windows arm64, macOS Intel and Linux arm64 run only the real-shell suite, not the browser suite or the installers.
- Nothing is signed or notarized; the macOS app is launched after `xattr -cr`, which a downloaded dmg would not get.
- Tier 1 ARIA matching is partial: an added control does not fail it, only a missing or renamed one does.
